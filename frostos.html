PROJECT 002 / SYSTEMS

FrostOS.

IN DEVELOPMENT

A 64-bit operating system built on a custom kernel, designed for lightweight embedded workloads such as corporate computer fleets. Not another distro. A kernel of our own.

THE IDEA

A kernel that stays skinny.

Most machines in an office do one job all day. They browse, they run a few internal programs, they sit on a desk for years. Give them a full general purpose desktop stack and most of it is dead weight.

FrostOS approaches the problem at the lowest layer: a custom 64-bit kernel written to boot fast, use little memory, and stay up through long unattended shifts. The desktop around it is assembled from exactly the parts each deployment needs, nothing more.

The first target class for the system is lightweight embedded work: point of sale terminals, signage, managed desktops, and locked-down corporate computers that need to be predictable rather than powerful.

CURRENT DEVELOPMENT

What works so far.

The build is currently concentrated on the kernel core and its most basic services.

01

Kernel core

The 64-bit kernel bring-up: boot, memory management, and a scheduler tuned for a small number of long-running tasks instead of thousands of chatty threads.

02

Frost layer

A thin compatibility layer that gives existing Linux applications a familiar surface to run against, so useful software is available before any porting work.

03

Image pipeline

The build system produces one reproducible system image per deployment role, so a fleet of computers can be provisioned and replaced like hardware, not pets.

WHERE WE WANT TO TAKE IT

Run the software you already own.

The plan for FrostOS includes a compatibility layer for Linux applications, and a Windows application layer behind it. Business software usually outlives the machines it runs on, and rewriting it before switching platforms is a cost few orgs can justify.

The combination is meant to work like this: a corporate computer runs FrostOS at its core, gets the light footprint and long uptimes of a custom kernel, and keeps running the internal programs it was already using, Linux ones through the native layer and Windows ones through the compatibility path.

FrostOS is in early development. The current estimate for a first public release is Q2 of 2027. That date is a plan, and it will move as the kernel proves itself or fails to.
