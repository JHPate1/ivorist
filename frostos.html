PROJECT 002 / SYSTEMS

FrostOS A 64-bit kernel for machines that have one job

ALPHA 0.1.0 CUSTOM KERNEL TARGET Q2 2027

Not another distro. A kernel of our own.

Most machines in an office do one thing all day. They run a till, they display a timetable, they sit in a meeting room and show slides. Give that machine a full general purpose desktop stack and almost all of it is dead weight, burning cycles and updates no one asked for.

FrostOS starts underneath all of that. It is a custom 64-bit kernel written to boot fast, hold a small memory image, and stay up through long unattended shifts. Everything above the kernel is provisioned per role: one reproducible image per job a fleet of computers must do.

The first target class is lightweight embedded work: managed desktops, point of sale terminals, signage, locked-down corporate computers that need to be predictable rather than powerful.
